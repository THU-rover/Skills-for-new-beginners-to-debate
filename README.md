# 辩论新生备赛｜出论

一份给辩论新生阅读的出论教程，配一个可以逐步交互的AI技能。

拿到辩题后，先理解题目与双方责任，再带着个人思路讨论。技能帮助你比较路线、处理质疑，逐步形成全队能解释、能够继续核验的主案。

目前完成的是出论板块。写稿、质询训练、模辩和完整一周备赛流程将另行整理。

## 先启用技能

技能显示名称为“出论”，调用名为 `debate-case-coach`。

### 在Codex中打开本仓库

下载或克隆这个仓库，解压后在Codex中打开仓库文件夹。技能源文件已放在仓库的 `.agents/skills/debate-case-coach/` 中。

Codex会发现仓库里的技能。选择“出论”，或在支持技能提及的输入框中输入 `$debate-case-coach`。如果技能没有出现，重启Codex后再检查。

也可以在已有Codex对话中，请技能安装器从本仓库安装。

```text
使用 $skill-installer 安装这个仓库中的出论技能。
仓库 https://github.com/THU-rover/Skills-for-new-beginners-to-debate
技能目录 .agents/skills/debate-case-coach
```

安装与调用方式可对照 [OpenAI官方技能文档](https://developers.openai.com/codex/skills/)。不同客户端的技能选择入口可能不同。

### 在其他AI工具中使用

`出论.skill` 是包含技能目录的ZIP压缩包。根据工具支持的安装方式导入，或解压后使用其中的 `debate-case-coach` 文件夹。文件夹中的 `SKILL.md`、`references/` 和 `assets/` 应一起保留。

仅修改扩展名或上传压缩包，并不保证工具会启用技能。如果工具没有技能功能，可以先上传[阅读教程](docs/出论.md)，请AI按当前步骤指导，并提交自己的记录。此时以普通文档对话方式使用。

## 给出辩题，开始使用

第一次使用，复制下面这段话，换成自己的辩题与信息。

```text
使用 $debate-case-coach 带我出论。
我是辩论新生，请按《出论》的八步流程，一次带我完成当前一步。
先听我的理解，再帮我检查；卡住时请解释或示范一个局部。

辩题是“我们应不应该努力成为情绪稳定的大人”。
我方持反方，目前刚拿到辩题，还没有成熟思路。
现在是我自己准备，之后会和队友讨论。
比赛还有一周，赛制我稍后补充。
```

最简单也可以只说下面这些，技能会根据下一步需要补问信息。

```text
使用 $debate-case-coach。
辩题是“……”，我方是……方。
我刚开始准备，请从破题带我做。
```

如果已经有笔记或讨论结果，直接交给它，从当前阶段继续。

```text
使用 $debate-case-coach。我们已经讨论过一轮，下面是辩题、持方和两套候选路线。
请先判断目前进度，接着帮助我们比较路线与处理质疑。
请保留队员分歧，你补出的建议单独标记。

这里粘贴已有材料。
```

## 给完辩题后，会怎样推进

技能先读取你提供的材料，确认持方与进度。每轮通常围绕一个小任务推进，提一至三个相关问题。

例如在“情绪稳定”这道题中，它可能请你先想，稳定有好处与值得努力成为稳定的人之间，还需要哪些理由。你回答后，它会复述并检查推理；你卡住时，它可以解释、给候选方向，或示范一小段。

随着材料增加，会逐步形成以下成果。

| 阶段 | 你主要做什么 | 技能怎样协助 |
| --- | --- | --- |
| 1．任务卡 | 提供辩题、持方与安排 | 整理任务，标明未知信息 |
| 2．独立破题 | 先写自己的题意理解 | 检查关键词与双方责任，帮助理解最强对方 |
| 3．个人框架 | 提出比较标准与候选路线 | 检查路线差别、比较优势与缺口 |
| 4．汇报复述 | 提交各人的材料并互相确认 | 整理路线总表，保留提出者与分歧 |
| 5．合作补强 | 对齐讨论对象，补齐路线 | 检查合并条件，标出候选机制 |
| 6．集中质疑 | 逐项提出最关键的问题 | 定位具体连接，合并重复问题 |
| 7．处理补证 | 改写、查证并选择主案 | 判断哪些要改框架、查资料或准备攻防 |
| 8．确认框架 | 全队复述，安排下一步 | 整理主案、待办和可接续的进度卡 |

八步用于说明工作顺序。已有成果可以接续，发现关键问题可以返回修改，也可以明确要求直接示范一套候选框架。

## 怎样与教程配合

先读当前一步，自己试写，再把结果交给技能检查。准备个人材料时可使用下面的请求。

```text
我读完第二步了，下面是我的独立破题。
请检查关键词有没有接到论证责任上，先指出最需要继续想的一处，让我试着回答。
```

开会后，可以把各人的材料或转写记录交给技能。

```text
这是四位队员的准备材料和本轮会议记录。
请整理各人的主张、逻辑链、比较优势和未决问题，保留出处。
先让我们确认是否整理准确，再帮助我们处理最影响主案去留的质疑。
```

遇到大量质疑时，可以这样继续。

```text
请逐项判断这些质疑成立后会影响什么。
说明哪些必须改框架，哪些需要查证，哪些可以准备攻防。
查证任务请写明要验证的具体判断，以及什么结果会要求改案。
```

结束前，让技能整理一张进度卡。换会话或换队员接手时，将它和新材料一起提供。

```text
请整理当前进度卡，保留辩题、持方、已确认框架、关键未决问题和下一项任务。
区分已经决定、暂定和待核验的内容，方便下次继续。
```

## 使用时留意

- AI提出的机制与论点属于候选，需要理由和证据支持。逻辑完整与证据成立需要分别检查。
- 资料检索取决于使用环境的联网能力。没有检索工具时，技能会列出查证任务，并标明尚未核实。
- 会议录音、转写由已有会议工具完成。技能可以整理提交的记录，不能代替队员确认真实意思。
- 尚有影响去留的核心缺口时，只确认暂选框架，并约定验证期限与改案条件。
- 教程与技能尚需通过真实的新生备赛持续调整，欢迎用具体卡点反馈。
