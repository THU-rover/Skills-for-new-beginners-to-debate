# 出论｜从个人思考到全队主案

拿到辩题后，先给自己一点独立思考的时间，再带着初步判断和队友讨论。这份教程带你走完八步，得到一套全队能解释、能够继续核验的主案。

你可以边读边用配套的“出论”技能。每完成一步，把自己的记录交给它，请它检查，再进入下一步。不需要读完整篇才开始。

## 怎样开始

使用支持本技能的AI环境时，选择“出论”技能，或输入下面这句话。

> 使用 $debate-case-coach 带我出论。我是新生，请按《出论》的八步流程，一次带我完成当前一步。先听我的理解，再帮我检查。

接着给出完整辩题、持方和目前进度。赛制、比赛日期等已知信息可以一起提供，不清楚的先标记。已有笔记就直接交给它，继续当前阶段。

两种使用场景都可以。

- 自己准备时，用它理解题意、检查推理，整理会前材料。
- 全队讨论时，把各人的材料和会议记录交给它，请它整理路线与问题，帮助全队作决定。

这套流程暂按单题单方、四人队伍设计，其他人数与双持可调整。时间仅供安排参考。技能包不负责录音，需要时使用已有会议工具转写，再交给AI整理。

## 先记住三个词

**论证责任**是要让裁判接受本方立场，至少需要交代清楚的事情。例如证明稳定有好处以后，还要解释为什么值得努力去追求。

**比较框架**说明双方分别建议什么，用什么标准判断，以及为什么采用这些标准。判准是其中用于评价的部分。

**机制**解释中间的变化怎样发生。写出“追求稳定 → 压抑表达”时，还需要解释什么条件让前者增加后者。

## 会前｜每个人先准备

### 第一步　把任务说清楚

队长将完整辩题、持方、赛制与比赛时间放进共用文档，写明这次讨论要完成什么。大家都在同一个任务下准备。

**做完留下**一张任务卡。缺失信息标记清楚即可。

**可以这样交给技能**

> 这是我们的辩题和比赛安排，请整理任务卡，只追问会影响下一步的重要信息。

### 第二步　独立破题，把关键词接到证明任务上

先自己想十至二十分钟，用自己的话复述题目。圈出关键的词或词语组合，继续问它们会让双方多承担什么证明任务。

以“我们应不应该努力成为情绪稳定的大人”为例。

| 关键词 | 往下追问 |
| --- | --- |
| 情绪稳定 | 比较的是怎样的状态？允许表达、愤怒与求助吗？ |
| 努力成为 | 可以怎样改变？投入有什么收益与成本？ |
| 大人 | 成年生活中的哪些处境，会让这项选择值得讨论？ |
| 应不应该 | 哪些理由足以支持这项建议，哪些代价会改变判断？ |

然后分别写出双方需要证明什么，替对方写一个最有道理的版本。最后提出一两个可能的切入点，并标出哪里还没有想通。

例如反方可以检验追求稳定的成本，但需要面对允许合理表达的正方。不能直接将“努力稳定”解释成“禁止哭泣”。

**做完留下**题意复述、双方责任、最强对方和初步思路。允许粗糙与不完整。

**可以这样交给技能**

> 这是我的独立破题。请检查关键词有没有接到论证责任上，指出最需要我继续想的一处，先让我回答。

如果连题意都读不懂，可以提前请技能解释词义、提问引导，理解后自己写一版。

### 第三步　确认个人暂定框架，带着路线去开会

回看前面的记录，回答双方真正要比较什么，以及我方可能在哪里有优势。

本题可以先讨论，朝稳定努力与针对具体困扰作调整，是否真的带来不同的行动。再比较收益、投入和表达空间。这个框架需要理由，仍可能在会议上修改。

选择一至两条候选路线，每条写清主张、推理过程和相对优势，再写一个最强反驳。让技能检查缺口，或提出采用不同机制的备选路线。

**做完留下**一份暂定比较框架和一至两条候选路线。

**可以这样交给技能**

> 这是我的比较框架和候选路线。请把最强对方放进来检验，看看我方还多出什么，再帮我整理会前材料。

### 会前带齐这张清单

每人准备一至两页短记录，回答以下问题。没有答案的地方写明卡在哪里。

- [ ] 我理解的完整题意是什么，关键词怎样影响双方责任？
- [ ] 双方至少需要证明什么，对方最有道理的版本是什么？
- [ ] 双方共同目标与实质分歧在哪里，我建议怎样比较？
- [ ] 我带来哪一至两条路线，它们怎样支持辩题结论？
- [ ] 对方也能获得相关好处时，我方还多出什么？
- [ ] 最强反驳是什么，最缺哪一步解释或证据？

使用过AI的队员，另记一处自己采纳或拒绝的建议及理由。

## 会中｜把个人思路变成全队主案

开场先默读各人材料。安排主持人推进议程，记录员维护共用文档，工作可以轮换。录音转写可以辅助核对，会议中同步记录各轮结果。

### 第四步　轮流讲，让队友确认听懂了

每人用三至四分钟介绍框架、路线和疑问。其他人先记质疑，必要时问澄清问题。讲完后，由队友复述主要推理，请提出者确认。

全部汇报完，再请技能整理相似点与分歧。大家核对自己的意思有没有被改变。

**做完留下**一张带有提出者的路线总表。

**可以这样交给技能**

> 这是四位队员的材料和会议记录。请分别整理主张、逻辑链、比较优势与缺口，保留分歧。你补出的建议另列，先不要选案。

### 第五步　对齐框架，一起补强候选路线

先检查大家是否在讨论相同的对象与选择。若一人批评“不许表达”，另一人讨论“学习调节”，先处理这项差别。

相近路线可以合并，前提冲突的暂时并列。对保留的两三条路线，全队先合作补上缺失的环节与边界，再进行质疑。新增解释仍需检验。

**做完留下**两三条可比较的候选路线，以及暂时采用的比较框架。

**可以这样交给技能**

> 请检查这些路线能否合并，指出前提冲突，并帮助补强。新增的机制与解释请标为待验证。

### 第六步　逐项质疑，问到具体一步

先各自默写问题，每人优先提一个最影响路线去留的质疑。说明它针对哪句话，以及成立后会让主案失去什么。

例如“正方也能复盘，因此你方还没说明遗憾的额外价值”，已经指出比较缺口，便于全队集中回应。

一次处理一个问题。确认质疑后，让队友回应，再判断缺口是否解决。五至八分钟还无法判断，就记录分歧与所缺信息，继续下一项重要问题。

**做完留下**问题表，至少记下问题、对应环节、当前处理和下一步任务。

**可以这样交给技能**

> 请把这些质疑按具体环节合并，先挑最影响去留的一项，带我们讨论。不要一次新增大量反驳。

### 第七步　决定改框架、查资料，还是准备攻防

对每个问题先问，假设质疑成立，我方需要撤回什么，撤回后还能完成责任吗？

| 问题影响 | 怎样处理 |
| --- | --- |
| 核心前提、机制或比较优势 | 定案前修改、补齐或重构 |
| 事实、因果、发生概率与效果 | 查资料，判断支持到哪里 |
| 已明确立场的误解或局部例外 | 核对边界，准备攻防回应 |

一个问题可以同时需要这几种处理。必要机制应当写进框架，资料支撑它，攻防再帮助现场解释。

例如“追求稳定会增加情绪表演”遭到质疑，就要核验目标怎样改变应对行为。只找到“表演与耗竭有关”的材料，前面的连接仍未解决。

每项查证任务写清要验证什么、材料需要支持哪一步，以及什么结果会要求改案。查证后再选主案。暂时搜索不到，也不能直接认定相关事实不存在。

**做完留下**主案选择、问题处理结果和有负责人与期限的任务表。

**可以这样交给技能**

> 请逐项判断这些问题怎样处理，说明理由。需要查证的写成具体任务，最后检查哪些问题仍然阻碍定案。

### 第八步　确认一份全队能复述的框架

将框架压缩为一至两页，详细逻辑链与资料另附。至少包括题意边界、双方责任、比较框架、主案总链、分论配合、机制证据、核心交锋和后续安排。

每个人不看稿，用一分钟解释我方立场、最强对方与我方优势。理解有差异，就回到对应位置修改。

影响主案去留的缺口已经解决，便可确认当前框架，进入写稿与训练。仍有关键缺口，就标为暂选，约定验证期限与改案条件，先推进不依赖它的工作。

**做完留下**当前框架、待办与攻防记录。改案时同步更新旧回应。

**可以这样交给技能**

> 请依据已确认记录整理当前框架，区分已决定、暂定和待核验的内容。检查是否达到定案条件，再给我们一份下次继续用的进度记录。

## 下次怎样接着做

会话结束前，请技能整理进度记录。下次带上完整辩题、当前阶段、主案与未决问题即可继续。临时想不出思路时，可以让它解释或示范一个局部，再由自己试写。

保留自己的判断和队友的真实分歧。AI给出的候选解释需要核验，材料支持到哪里，主张就说到哪里。
