# 阶段执行与教学示例

## 会前阶段 1—3

阶段1提取任务信息。对已有记录直接整理；只在缺失内容影响下一项判断时询问。任务目标限定在出论，不自行扩成整周备赛或完整发言稿。

阶段2先让用户复述题意，识别人物、处境、行动与争议概念。关键词应组合理解，逐个落到讨论范围与证明要求。接着让用户试写双方责任、最强对方，以及一条带缺口的候选思路。

阶段3把共同目标与分歧放在一起，检验评价标准为何适用于题目，是否预先假定我方结论。让用户选择一至两条路线，分别写链条、比较增量与最强反驳。可补充不同机制的备选，但不给同一机制的改名版本充数。

会前记录应能回答六个问题：题意与关键词影响，双方责任与最强对方，共同目标与分歧，比较标准与理由，候选链条与增量，最强反驳与最缺的信息。已有材料不必按固定格式重写。

## 会议阶段 4—6

阶段4建议先默读，再轮流汇报，每人讲框架、路线与疑问，队友复述后由提出者核对。AI从笔记或转写整理路线，标出处与理解不明的位置。没有真实核对时明确记录待确认。

阶段5先处理题意、责任与比较对象冲突。合并前说明合并的依据，写出新链，保留修改痕迹。先为每条路线补出合理边界与中间环节，再公平检验。人数较少或时间紧时保留最有意义的两条即可。

阶段6先收队员问题，再补少量AI发现的关键遗漏。质疑定位到主张或链条编号，并说明成立后的后果。按题目相关性、比较优势、机制、证据和局部表达安排优先级。每轮先复述问题，再回应并记录是否真正解决；没有信息增量时转为待验证任务。

## 处理阶段 7—8

阶段7依次判断质疑是否针对真实主张、成立需要哪些条件、会撤回哪个环节，以及撤回后能否完成责任。按缺口分配逻辑解释、经验查证、价值比较与边界回应，不将所有问题一律交给搜索。

对证据报告追问材料实际说明什么、用于哪一步、能否推广到当前情境。说明支持、支持较窄判断、不支持、反证与未找到之间的区别。选择主案时检查核心前提相容、收益没有重复计算、分论责任不遗漏。偏好投票只能辅助排序。

阶段8整理短总图，细节另附；核心未决问题决定暂选或确认，不由文档格式齐全决定。建议队员各自复述，并同步更新旧攻防。结束时给可携带的进度卡，供其他会话续接。

## “情绪稳定”示例的使用边界

以下用于教学，不是已经证实的立论或论文结论。不要主动把其他题目强套到这个案例。

题目为“我们应不应该努力成为情绪稳定的大人”。

- 关键词组合：“努力成为”要求考虑改善路径与投入，不能只论证理想状态有好处。“大人”提供生活处境，不自动证明应当稳定。
- 最强对方：允许合理表达、求助、愤怒与恢复过程的正方，仍能主张长期改善。反方需处理这个版本。
- 候选框架：比较长期朝稳定努力与具体问题导向的建议，对收益、成本及表达行动空间的影响。先检查两个方案有无实质区别，普遍倡导范围需要论证。
- 正方候选：目标指导准备与回顾，从而积累应对经验。缺口是具体问题导向也能积累，长期目标额外增加了什么。
- 反方候选：稳定与成熟评价绑定可能增加掩饰，再产生消耗。缺口是从倡导到掩饰的连接，以及为何允许表达的版本仍承担足够成本。

示范一轮教学：先请用户指出反方链条最弱的一步。若用户以“研究证明掩饰有害”回应，解释该材料仍未连接倡导与掩饰，随后请其提出一个可能条件。条件提出后标为候选机制，再生成查证任务，不能直接宣布补证完成。

另一个检验例：“对方也能复盘”会影响遗憾的独占性主张。应重做比较，不能通过重新定义遗憾把对方全部收益收归己方。若主张更容易调用信息，则提出对应的经验核验任务。
